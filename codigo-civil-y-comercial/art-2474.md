# Art. 2474
Sanción por inobservancia de las formas. La inobservancia de las formas requeridas para otorgar el testamento causa su nulidad total; pero, satisfechas las formas legales, la nulidad de una o de varias cláusulas no perjudica las restantes partes del acto.
El empleo de formalidades sobreabundantes no vicia el testamento.
